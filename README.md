# 🌿 Personalized Haircare & Lifestyle Recommendation System

## 📌 Overview

The **Personalized Haircare & Lifestyle Recommendation System** is a data-driven project that provides personalized haircare and lifestyle recommendations based on users' **hair characteristics, scalp conditions, lifestyle habits, diet, and hair concerns**.

The project uses **EDA, feature importance analysis, and K-Means clustering** to identify patterns among users and generate suitable recommendations.

## 🎯 Objectives

* Analyze factors affecting hair and scalp health.
* Identify important features related to hair concerns.
* Segment users using **K-Means clustering**.
* Provide personalized haircare, diet, and lifestyle suggestions.
* Develop an interactive **Streamlit application**.

## 📊 Dataset

The dataset was collected through a **Google Form survey** with approximately **463 responses**.

It includes information about:

* Hair type, texture, and density
* Scalp type and condition
* Hair concerns
* Diet and water intake
* Sleep, stress, and exercise
* Heat, sun, and chemical exposure
* Family and medical history

## 🤖 Methodology

```text
Data Collection
      ↓
Data Preprocessing
      ↓
EDA & Feature Analysis
      ↓
Feature Importance
      ↓
K-Means Clustering
      ↓
User Segmentation
      ↓
Personalized Recommendations
```

### Clustering Results

* **Algorithm:** K-Means
* **Number of Clusters:** 2
* **Silhouette Score:** 0.0618
* **Davies-Bouldin Index:** 3.7837
* **Calinski-Harabasz Score:** 28.4179

## 🧴 Recommendations

The system provides suggestions related to:

* Shampoo and haircare categories
* Hair masks and remedies
* Diet and water intake
* Lifestyle improvements
* Haircare Do's & Don'ts
